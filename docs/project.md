# PAIN Pizza
PAIN Pizza is an application that allows users to order pizza online. It provides a user-friendly interface for browsing the pizza menu, customizing orders, and making payments. The application also includes features for tracking orders and managing user accounts.

# Goals
1. Authenticated users can search and order pizza online.
2. Allow users to customize their pizza orders with various toppings and crust options.
3. Provide a secure and efficient payment system for processing orders.
4. Enable users to track the status of their orders in real-time.
5. Implement a user account management system for storing order history and preferences.

# User Flow
1. User signs up or logs in to their account.
2. User browses the pizza menu and selects their desired pizza.
3. User customizes their pizza order by choosing toppings, crust type, and size.
4. User adds the customized pizza to their cart and proceeds to checkout.
5. User enters payment information and confirms the order.
6. User receives an order confirmation and can track the status of their order in real-time.
7. Once the order is delivered, the user can provide feedback and rate their experience.

# Features
## User Authentication
- Sign up and login functionality for users to create and access their accounts.
## Pizza Menu
- A comprehensive menu showcasing various pizza options with descriptions and prices.
- An intuitive interface for users to browse and select their desired pizza.
## Pizza Customization
- Options for users to customize their pizza orders with various toppings, crust types, and sizes.
## Payment Processing
- Integration with secure payment gateways to process orders efficiently.
## Order Tracking
- Real-time tracking of order status from preparation to delivery.
## User Account Management
- A system for users to manage their accounts, view order history, and save preferences.

# Success Criteria
1. Users can successfully create accounts and log in to the application.
2. Users can browse the pizza menu and customize their orders without any issues.
3. The payment system processes orders securely and efficiently.
4. Users can track their orders in real-time and receive accurate updates on their status.
5. Users can manage their accounts and view their order history seamlessly.
