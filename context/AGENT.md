# Agent Context

Read the following files in order before implementing any features or making any decisions:

1. [constitution.md](./core/constitution.md) - The highest authority document that outlines the fundamental principles and rules governing the project. It must be followed at all times and takes precedence over any other guidelines or policies.
2. [dependencies.md](./core/dependencies.md) - This file lists all the approved dependencies for the project. You must not install any dependencies that are not listed here without approval from the user.
3. [backend.md](./core/backend.md) - This file contains specific guidelines and rules for implementing backend features. It must be followed when working on any backend-related tasks.
4. [frontend.md](./core/frontend.md) - This file contains specific guidelines and rules for implementing frontend features. It must be followed when working on any frontend-related tasks.
