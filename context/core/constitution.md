# Dependency Policies
1. You should never install any dependencies that are not listed in the constitution file [dependencies.md](./core/dependencies.md)
2. If you need to add a new dependency, you must first tell the user WHY you need it and get their approval before proceeding. Always provide a clear justification for why the new dependency is necessary and how it will benefit the project.
3. Any new dependency must be added to the dependencies file [dependencies.md](./core/dependencies.md) with a short, clear explanation of its purpose and how it will be used in the project.
4. Only install dependencies that are essential for the functionality of the project. Avoid adding unnecessary dependencies that could bloat the project or introduce security vulnerabilities.
